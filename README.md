# StrayHome｜社會議題倡議連署網站（課堂模擬）


「牠有家人，卻聯絡不上。」
受傷的浪浪有晶片、有登記飼主，送醫後卻聯絡不上時，醫療同意、費用與歸還該怎麼辦？本站以兩則真實個案說明困境，呼籲主管機關研議緊急醫療處理程序。

> 課堂模擬網站，不是正式救援平台；模擬連署不會送出、不保存任何資料。

## 網站結構
1. 01 故事：聯絡不上怎麼辦？
2. 02 數據：家貓、家犬數量與登記率（分頁切換圖表）
3. 03 個案：臺中沙鹿橘貓、臺南小黑
4. 04 連署：模擬連署表單
5. 我該怎麼做？：救援端（六都通報電話、送醫後三件事）／飼主端（30 秒晶片檢查）
6. 資料出處

## 技術
- 單一 `index.html`，原生 HTML、CSS、JavaScript，無框架與第三方套件
- 色彩以 OKLCH 定義，字階與間距使用 `clamp()` 流體數值，支援深色模式與減少動態
- 像素插畫以程式繪製 SVG；跟隨游標的小黑／小橘以 `requestAnimationFrame` 實作
- FAQPage JSON-LD 結構化資料

## 本機預覽
直接用瀏覽器開啟 `index.html` 即可。
